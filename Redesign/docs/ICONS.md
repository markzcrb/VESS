# Icons → SF Symbols

The Figma icons (`Icon/*`) are stand-ins drawn to look like SF Symbols. In the app, use the SF Symbol below.
- Rendering: monochrome. Colour comes from `textSecondary` (rows), `textPrimary` (nav and buttons) or a metric hue (metric context only).
- Weight: `.regular`. Row icons use a 17 pt font in a 20 pt frame; nav icons use 22–24 pt.
- Names marked * should be checked in the SF Symbols app, since availability varies by iOS version.
